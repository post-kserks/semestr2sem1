# Student System

Простая система управления данными студентов на C++. Проект создан в рамках учебного семинара.

## Функциональность
*   **Класс Student**: Хранение ID, имени и оценок студента. Расчет среднего балла.
*   **Класс StudentGroup**: Управление набором студентов, поиск по ID и расчет среднего балла всей группы.
*   **Архитектура**: Разделение на заголовочные файлы (`.h`) и файлы реализации (`.cpp`).

## Структура проекта
*   `include/` — заголовочные файлы классов.
*   `src/` — реализация методов классов.
*   `main.cpp` — демонстрация работы и тесты.
*   `CMakeLists.txt` — конфигурация сборки.

## Как собрать и запустить

### Требования
*   Компилятор C++ с поддержкой стандарта C++17.
*   Установленный CMake.

### Сборка
1. Создайте директорию для сборки:
   ```bash
   mkdir build
   cd build
   ```
2. Сгенерируйте файлы сборки и скомпилируйте:
   ```bash
   cmake ..
   make
   ```

### Запуск
После успешной сборки запустите исполняемый файл:
```bash
./StudentSystem
```

## Улучшения в этой версии
1.  **Константность**: Методы, не изменяющие состояние объектов (геттеры, расчеты), помечены как `const`.
2.  **Эффективность**: Оптимизированы циклы и передача данных (использование константных ссылок вместо копирования векторов).

4.  **Расширенные тесты**: В `main.cpp` добавлен полноценный сценарий тестирования групп и поиска студентов.
