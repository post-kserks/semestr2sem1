## Инструкция по сборке

Для сборки проекта вам понадобится компилятор с поддержкой C++17 и установленный CMake.

```bash
# 1. Создание директории для сборки.
mkdir build
cd build

# 2. Генерация файлов сборки через CMake
cmake ..

# 3. Компиляция проекта
make

# 4. Запуск программы
./StudentSystem
```

## Описание классов и методов

### Класс `Student`
Представляет отдельного студента. 
*   `addGrade(int grade)` — добавляет оценку в список.
*   `calculateAverage()` — вычисляет средний балл студента.
*   `printInfo()` — выводит краткую сводку (ID, имя, балл).
*   Геттеры: `getId()`, `getName()`, `getGrades()`.

### Класс `StudentGroup`
Управляет коллекцией студентов.
*   `addStudent(const Student& student)` — зачисляет студента в группу.
*   `findStudentById(int id)` — поиск студента (возвращает указатель для возможности редактирования).
*   `calculateGroupAverage()` — расчет среднего балла по всем оценкам всех студентов группы.
*   `getStudentCount()` — общее количество студентов.
*   `printAllStudents()` — вывод полного списка группы.

## Проблемы и решения

### Раздел технического писателя (Диалоги с ИИ)

**Диалог №1: Проблема эффективности**
> **Чекулаева:** "Нейросеть, при расчете среднего балла группы мы каждый раз копируем векторы студентов. Как это оптимизировать?"
> **ИИ:** "Для повышения производительности следует использовать константные ссылки (`const std::vector<int>&`) вместо передачи по значению. Это исключит лишнее выделение памяти на куче при каждом вызове метода."

**Диалог №2: Безопасность памяти**
> **Чекулаева:** "Что будет, если метод поиска студента не найдет ID? Как не допустить падения программы?"
> **ИИ:** "Метод должен возвращать `nullptr`, а вызывающая сторона обязана проверить результат. В финальной версии мы добавили проверку `if (foundStudent)`, чтобы предотвратить разыменование пустого указателя."

**Диалог №3: Постоянство данных**
> **Чекулаева:** "Как гарантировать, что методы вывода информации случайно не изменят поля объекта?"
> **ИИ:** "Необходимо пометить такие методы спецификатором `const`. Это заставит компилятор следить за неизменяемостью объекта и позволит вызывать эти методы для константных экземпляров классов."
